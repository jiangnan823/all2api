# all2api 面板操作边界矩阵（v1.0）

> 回答一个问题：**面板上每一块内容，用户能不能操作？** 每个元素必须落在本表一行里，禁止"可看可改"的模糊态。
> 原则：**文件即账号**（auths\ 是账号的物理事实源，面板不重复建设账号管理）；**上游协议未知的能力不做假开关**。

## 1. 账号池屏（/api/accounts）

| 元素 | 可操作？ | 说明 |
| --- | --- | --- |
| 状态卡（总数/可用/冷却/禁用/积分合计） | ❌ 只读 | 派生自池快照 |
| 账号表格：platform / id / credit / health / expires_at / cooldown_end | ❌ 只读 | id 行内复制按钮 ✅（纯前端动作） |
| 账号表格行内 recover 按钮 | ✅ 可操作 | `POST /api/accounts/{source}:{id}/recover`（已有端点）：重置冷却+熔断。**不改变 disabled（凭证死亡）**——按钮置灰，提示"凭证已失效，请更换 auths\ 文件" |
| 凭证新增/删除/编辑 | ❌ 无入口 | **文件即账号**：引导去 auths\ 目录操作（空池引导文案同理）；面板重启后自动发现 |
| 手动"立即播种余额" | ❌ 无入口 | 启动时自动播种（已实现）；运行中重播种属 P1 |

## 2. 任务屏（/api/tasks）

| 元素 | 可操作？ | 说明 |
| --- | --- | --- |
| 任务卡：中文名/说明/cron/enabled | ❌ 只读 | enabled 由 config.sources 定，配置屏改 |
| 最近运行统计（total/success/failed/skipped/at） | ❌ 只读 | 上次运行快照 |
| "立即执行"按钮 | ❌ **不做** | 调度器自动跑；手动批量触发需后端任务队列（P1 故事），本版做假按钮即撒谎 |

## 3. 模型屏（/api/models）

| 元素 | 可操作？ | 说明 |
| --- | --- | --- |
| 模型表（平台/模型名/来源徽标） | ❌ 只读 | 本地目录（静态表+ModelMap），带"上游实时查询未接入"诚实标注 |
| 平台过滤下拉 | ✅ 可操作 | 纯前端过滤 |
| 路由别名（model → platform）编辑 | ❌ 无入口 | ModelMap 语义尚未裁定（§9.21-e.2），不暴露 |

## 4. 日志屏（/api/logs）

| 元素 | 可操作？ | 说明 |
| --- | --- | --- |
| 日志列表/级别过滤/自动滚动/刷新 | ✅ 可操作（纯前端） | 不影响后端 |
| 日志清除/导出 | ❌ 无入口 | 环形缓冲 500 行，清除无意义；导出 P1 |

## 5. 连接屏（读 /api/config + /api/models）

| 元素 | 可操作？ | 说明 |
| --- | --- | --- |
| Base URL 展示 + 复制 | ❌ 只读 + ✅ 复制 | location.origin + /v1 |
| API Key 状态（已配置/开放模式） | ❌ 只读 | 实际改 key 在配置屏 |
| 模型清单 + 复制 | ❌ 只读 + ✅ 复制 | 从模型屏数据复用 |

## 6. 配置屏（既有 SettingsScreen，边界沿用）

| 元素 | 可操作？ | 说明 |
| --- | --- | --- |
| fields 下发的全部字段（listen/api_key/pool/schedule/sources.throttle...） | ✅ 可操作 | `POST /api/config`，字段级校验；`api_key`/`listen` 标 restart_required |
| requiresConfirm 字段（指纹开关） | ✅ 需二次确认 | DangerAction 逐字确认（UI UE §5.13 冻结） |
| 保存按钮 | ✅ | dirty 非空才激活；成功后以 applied 重建基线 |
| API Key 临时注入（面板自身请求带头） | ✅ 内存态 | 不落 storage（M1 红线）；与"保存 api_key"是两件事，文案区分 |

## 7. 全局

| 元素 | 可操作？ | 说明 |
| --- | --- | --- |
| 主题切换（明/暗） | ✅ | 内存态 |
| topbar 状态 pill（连接/离线/401 + 手动重探） | ❌ 只读 + ✅ 重探按钮 | |
| 任何 storage 写入 | ❌ 永不 | M1 红线 |

## 8. 边界条件清单（每条都要有界面表现）

| # | 条件 | 界面表现 |
| --- | --- | --- |
| C1 | 池为空（无凭证文件） | 账号池屏整页引导卡："把 workbuddy-*.json 放入 auths\ 后重启"；不显示空表格 |
| C2 | 部分账号积分 0（floor 以下） | 状态徽标"额度不足"；不参与选号（提示文案说明 credit_floor） |
| C3 | 账号 disabled（凭证死亡） | 红徽"凭证失效"+ 行内提示换文件；recover 按钮置灰 |
| C4 | 账号 cooling | 黄徽"冷却中"+ 冷却截止时间倒计时 |
| C5 | 全部账号冷却/不足（请求将 503） | 池顶横幅："当前没有可服务账号，请求会返回 503"，不用红（不是错误，是状态） |
| C6 | /api/* 401（key 不符） | pill=未授权；各数据屏显示"密钥不匹配"而非假错误；引导去配置屏改 key |
| C7 | 后端离线/端口不对 | pill=离线；全部数据屏重试按钮 + 诊断信息 |
| C8 | 任务从未运行过（新装） | last_run 显示"尚未运行（cron: …）"，不是"—"更不是 0 |
| C9 | 日志为空 | "暂无日志"空态 |
| C10 | 模型目录为空（ModelMap 空+静态表缺失） | 明示"本地目录为空，请确认构建变体"，不显示假列表 |
| C11 | 保存配置字段级失败 | field_errors 逐字段红字（key+message），保存按钮恢复可点 |
| C12 | 凭证将在 7 天内到期 | expires_at 黄色预警（自动刷新通常无感，预警只是提示） |
