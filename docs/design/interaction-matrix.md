# all2api 面板操作边界矩阵（v1.1）

> 回答一个问题：**面板上每一块内容，用户能不能操作？** 每个元素必须落在本表一行里，禁止"可看可改"的模糊态。
> v1.1 变更（主人裁定）：① 信息架构改为**按平台分面板**（顶栏平台选择器，账号/任务/模型各自归属平台）；② **添加账号是面板内一等操作**（"文件即账号"废止；文件只是凭证的落盘位置，用户不必碰文件）。原则保留：**上游协议未知的能力不做假开关**。

## 0. 顶栏平台选择器（新增）

| 元素 | 可操作？ | 说明 |
| --- | --- | --- |
| 平台切换 [WorkBuddy / Qoder / Trae] | ✅ 可操作 | 切换后账号池/任务/模型三屏全部过滤为该平台；内存态，不落 storage |
| 各平台启用状态点 | ❌ 只读 | enabled=false 显示"未启用"徽标 |
| 未启用平台点进去 | ✅ | 只显示"启用此平台"引导（写 config.sources.<id>.enabled），不显示假数据 |

## 1. 账号池屏（按平台；/api/accounts 过滤 platform）

| 元素 | 可操作？ | 说明 |
| --- | --- | --- |
| 状态卡（总数/可用/冷却/禁用/积分合计） | ❌ 只读 | 该平台范围 |
| **添加账号按钮** | ✅ 可操作 | 打开该平台的添加向导（见 §1a） |
| 账号表格：platform / id / credit / health / expires_at / cooldown_end | ❌ 只读 | id 行内复制按钮 ✅（纯前端动作） |
| 账号表格行内 recover 按钮 | ✅ 可操作 | `POST /api/accounts/{source}:{id}/recover`：重置冷却+熔断。凭证失效（disabled）置灰并提示"重新添加" |
| **删除账号**（行内） | ✅ 可操作（P0） | 删除 = 删凭证文件（qoder 为 pat.txt 时需确认影响唯一账号）+ 池移除 + 热生效；DangerAction 确认（凭证是不可再生的登录态，必须显式确认） |
| 手动"立即播种余额" | ❌ 无入口 | 启动时自动播种（已实现）；运行中重播种属 P1 |

### §1a 添加账号向导（按平台分化；v1.1 核心）

| 平台 | 向导元素 | 可操作？ | 依赖后端 |
| --- | --- | --- | --- |
| qoder | PAT 粘贴框（`pt-…`）+ 保存 | ✅ | `POST /api/accounts/qoder`（panel 批）：写 auths/qoder-pat.txt + 热注册 + 播种；重复粘贴=替换并提示 |
| workbuddy | **凭证 JSON 粘贴框**（从官方桌面端 auth\*.info 复制）+ 保存 | ✅ P0 | `POST /api/accounts/workbuddy`：校验字段（uid/accessToken/refreshToken/expiresAt）→ 写 `workbuddy-<uid>.json` + 注册 + 播种 |
| workbuddy | 设备授权三步流（取链接→浏览器登录→粘贴回调） | ✅ P1 | `POST /api/accounts/workbuddy/login-url` + `…/complete`（协议报告 §3 已实证三端点） |
| trae | 向导整体 | ❌ | 平台未接入：显示"该平台尚未接入网关"，不渲染假表单 |
| 通用 | 添加成功即时刷新账号池；重复 uid 幂等覆盖并提示 | — | — |

## 2. 任务屏（按平台；/api/tasks 过滤 platform）

| 元素 | 可操作？ | 说明 |
| --- | --- | --- |
| 任务卡：中文名/说明/cron/enabled | ❌ 只读 | workbuddy 四任务；**qoder/trae 无任务面 → 屏显"该平台暂无定时任务"**，不渲染假卡片 |
| 最近运行统计（total/success/failed/skipped/at） | ❌ 只读 | 上次运行快照 |
| cron 编辑 | ✅ 经配置屏 | 任务屏只读展示，跳转链接到配置页对应字段（避免两处编辑同一值） |
| "立即执行"按钮 | ❌ **不做** | 调度器自动跑；手动批量触发需后端任务队列（P1 故事） |

## 3. 模型屏（按平台；/api/models 过滤 platform）

| 元素 | 可操作？ | 说明 |
| --- | --- | --- |
| 模型表（模型名/来源徽标） | ❌ 只读 | 本地目录（该平台静态表+ModelMap），带"上游实时查询未接入"标注 |
| 路由别名（model → platform）编辑 | ❌ 无入口 | ModelMap 语义尚未裁定（§9.21-e.2），不暴露 |

## 4. 日志屏（全局，不随平台切换；/api/logs）

| 元素 | 可操作？ | 说明 |
| --- | --- | --- |
| 日志列表/级别过滤/**平台过滤**/自动滚动/刷新 | ✅ 可操作（纯前端） | 平台过滤按行内 platform 标记 |
| 日志清除/导出 | ❌ 无入口 | 环形缓冲 500 行；导出 P1 |

| 元素 | 可操作？ | 说明 |
| --- | --- | --- |

## 6. 配置屏（全局；既有 SettingsScreen，边界沿用）

| 元素 | 可操作？ | 说明 |
| --- | --- | --- |
| fields 下发的全部字段（listen/api_key/pool/schedule/sources.throttle...） | ✅ 可操作 | `POST /api/config`，字段级校验；`api_key`/`listen` 标 restart_required |
| 平台开关 sources.<id>.enabled | ✅ | 一键摘源；未启用平台在平台选择器显示引导 |
| requiresConfirm 字段（指纹开关） | ✅ 需二次确认 | DangerAction 逐字确认（UI UE §5.13 冻结） |
| 保存按钮 | ✅ | dirty 非空才激活；成功后以 applied 重建基线 |
| API Key 临时注入（面板自身请求带头） | ✅ 内存态 | 不落 storage（M1 红线）；与"保存 api_key"是两件事，文案区分 |

## 8. 边界条件清单（每条都要有界面表现）

| # | 条件 | 界面表现 |
| --- | --- | --- |
| C1 | 某平台池为空（无凭证） | 该平台账号池屏显示引导卡 + **「添加账号」按钮**；不显示空表格 |
| C1b | 平台未启用（enabled=false） | 平台选择器徽标"未启用"；点进去只有启用引导 |
| C2 | 部分账号积分 0（floor 以下） | 状态徽标"额度不足"；不参与选号（提示 credit_floor） |
| C3 | 账号 disabled（凭证死亡） | 红徽"凭证失效"+ 行内"重新添加"引导；recover 置灰 |
| C4 | 账号 cooling | 黄徽"冷却中"+ 冷却截止倒计时 |
| C5 | 当前平台全部账号不可用（请求将 503） | 池顶横幅"当前没有可服务账号，请求会返回 503"（状态非错误） |
| C6 | /api/* 401（key 不符） | pill=未授权；数据屏显示"密钥不匹配"，引导去配置屏 |
| C7 | 后端离线/端口不对 | pill=离线；全部数据屏重试按钮 + 诊断信息 |
| C8 | 任务从未运行过（新装） | last_run 显示"尚未运行（cron: …）" |
| C9 | 日志为空 | "暂无日志"空态 |
| C10 | 模型目录为空 | 明示"本地目录为空，请确认构建变体"，不显示假列表 |
| C11 | 保存配置字段级失败 | field_errors 逐字段红字，保存按钮恢复可点 |
| C12 | 凭证将在 7 天内到期 | expires_at 黄色预警 |
| C13 | 添加账号：粘贴非法内容（非 JSON/非 pt- 前缀） | 输入框下方即时红字，不落盘 |
| C14 | 添加账号：uid 已存在 | 覆盖前 DangerAction 确认"将替换现有凭证" |
| C15 | 删除唯一账号 | 确认文案明示"这是该平台最后一个账号，删除后该平台路由将不可用" |
